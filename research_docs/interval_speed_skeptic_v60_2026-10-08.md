# Independent interval speed audit v60

The frozen-yaw displacement Jacobian is correct. `python check_interval_jacobian_v60.py` independently differentiates the actual trajectory integrator with irregular timestamps, nonzero initial heading, seven feature columns and three intervals (21columns). Maximum analytic versus central finite-difference discrepancy is1.27510e-10. It includes intervals starting mid-recording, so the rotation from cumulative heading into interval-start heading is checked rather than assumed.

No C3D trajectory is used as predictor input. C3D heading/XY is used for fitting TRAIN displacement targets and for the allowed single initialization during evaluation. Held-out physics calibration, gravity-proxy yaw scalar/intercept, feature normalization and residual caps come from saved training-fold models whose fitting IDs are checked against current fitting membership. C3D intervals use valid endpoints and continuous IMU, so a target can legitimately span an optical gap, but no optical path shape through that gap is known. The estimator is offline because projected yaw uses forward/backward accelerometer filtering.

The system uses exact linear displacement supervision before clipping. Deployment clips predicted forward residual to the fitting-only cap and then multiplies by the fixed gain, so claims of a globally exact linear deployed predictor would be wrong. No winner exists here, so saturation cannot rescue a rejected result or require any validation search. The v59 independent source hash scan verified all reused fold models. v60's source does not itself verify those model hashes; adding a shared hash guard to future runs improves reproducibility without changing this completed result.
